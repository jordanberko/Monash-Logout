## 1. Where are answer sheet counts actually read?

**Priority:** High

**The question**

In each of the three sources, where does a checker read a number of answer sheets that can be compared against another source?

**What depends on it**

Section 8 now tells checkers that the eVigilation Hybrid field is a yes or no, that it is not a count, and that it cannot agree or disagree with a number. If eVigilation does in fact carry an answer sheet count, that instruction is wrong and every hybrid exam is being checked against the wrong field.

**What the sources say**

kayla_process.txt says: "Answer Sheets Discrepancy | Does the number of eVig match the number on eAssessment, flag a discrepancy if not." That implies eVigilation carries a number. The guide describes only a Hybrid yes/no flag. Both cannot be right.
